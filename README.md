# AI-Powered Job Market Analytics Dashboard

## Project Overview

This project analyzes job market trends in Data Science, Data Engineering, Machine Learning, and Data Analytics using Python and Power BI.

The objective is to identify hiring trends, salary patterns, company distributions, remote work opportunities, and experience-level compensation.

## Dataset

* Source: Data Science Jobs Salary Dataset
* Records: 565+
* Features: 14

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Power BI

## Project Workflow

1. Data Understanding
2. Data Cleaning
3. Feature Engineering
4. Exploratory Data Analysis
5. Job Market Analysis
6. Interactive Power BI Dashboard

## Key Insights

* Data Scientist is the most demanded role.
* Executive-level professionals earn the highest salaries.
* Medium-sized companies contribute the largest share of job postings.
* Remote work opportunities account for a significant portion of jobs.
* The United States dominates hiring in Data Science and AI-related roles.

## Dashboard Features

* Top Hiring Countries
* Salary Category Distribution
* Company Size Analysis
* Remote Work Distribution
* Experience-Level Salary Analysis
* Interactive Filters

## Conclusion

The dashboard provides insights into job market trends and salary distributions, helping job seekers, students, and professionals make informed career decisions.
